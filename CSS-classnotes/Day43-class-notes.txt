CSS Positions
---------------------------------------

CSS Position
- Generally, elements are placed according to the document layout flow.
- Position allows to make element behave differently and take them out of the document flow.
- CSS Positions are defined by using “position” style attribute.

1. static
2. absolute
3. fixed
4. sticky
5. relative

1.
static Position:
- It keeps element according to normal flow of the document.
- It will not allow to change the posistion of element.
- Static position is not affected by top, right, bottom, left  if defined.
- Generally in js, if we want to move the elements we can change its place,but if we don't want to change then we need to make those
  elements as "static".
- while designing a responsive design also the element should not be changed dynamically, then we need to for position as "static".

Fixed Position:
- The element is removed from normal document flow.
- Its position is fixed with left, right, top and bottom attributes.
- It will not move from the position defined.
- It locks the component at fixed position on page.
- It is attached to the browser of the page, it won't move along with content in the page.

Relative Position
- It is defined for parent element.
- The parent element keeps all child elements relative to the context.
- It requires placement of child element using absolute.
- Fixed will keep element regards to page.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="../node_modules/bootstrap-icons/font/bootstrap-icons.css">
    <style>

        #count{
            display: inline-block;
            height: 10px;
            width: 10px;
            border-radius: 10px;
            background-color: red;
            font-size:10px;
            text-align: center;
            color:white;
            position: absolute;
            top:-8px;
            right:-8px;
            bottom:-8px;
        }

        button{
            position: relative;
        }
    </style>
</head>
<body>
    <br><br>
    <button class="bi bi-cart4"><span id="count">4</span></button>
</body>
</html>

CSS Z-Index
===========
- It can take element back or backward.
- It can bring element front or forward.
- Z-Index starts with "0" index number which is back.

syntax: 
   a{
	z-index: 0;
   }
   b{
	z-index: 2;
   }
   c{
	z-index: 1;
   }

a -> bottom back
c -> over A
b -> over c
