CSS Text
  color
  text-align	  : left|center|right|justify
  text-shadow	   (same like box shadow)
  text-indent	  : First line of the paragraph with some space(length|initial|inherit)
  text-transform  : uppercase,lowercase,capitalize
  text-overflow   : It can display overflowing text with chars like ellipsis.
  text-decoration : overline,underline,linethrough,size,color.

While working with paragraph
  line-height    : space b/w lines
  word-space     : space b/w words
  letter-space   : space b/w chars
  word-break     : breaks lengthy words at right margin of paragraph. 
  white-space    : it controls wrapping of text in the container(nowrap).
  overflow	 : hidden|scroll|auto

CSS list styles
==============
    list-style 	       : shorthand
    list-style-type    : alpa|number|roman|disc|circle
    list-style-image   : custom images
    list-style-position: inside,outside

syntax: 
   list-style : list-style-type list-style-image list-style-position;

Note: If one of the values are missing, the default value for that property will be used.

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="shortcut icon" href="../public/images/favicon.ico" type="image/x-icon">
    <style type="text/css">
        ul {
            list-style-image	: url(../public/images/bullets.gif);  
            list-style-position : inside; 
        }
        li{
            border: 1px solid black;
            padding: 5px;
            width: 150px;
            margin-bottom: 5px;
        }   
    </style>
</head>

<body>
    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JS</li>
    </ul>
</body>

</html>

CSS 2D effects
==============
 => 2D refers to 2-Dimension effects
 => we can change the orientation and position of element along x and y axis.
 => you can configure by using "transform" attribute.
 => Transform method for 2D are
	a. translate()
	b. skew()
	c. scale()
	d. rotate()

translate() 
- It changes the position of element along x and y axis
	translate(x,y)
	translateX()
	translateY()

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="shortcut icon" href="../public/images/favicon.ico" type="image/x-icon">
    <style type="text/css">
        img{
            transform: translateX(0px);
            transition:3s;
        }
        img:hover{
            transform: translateX(800px);
            transition: 3s;
        }    
    </style>
</head>

<body>
    <img src="../public/images/a4.jpg" width="300" height="200">
</body>

</html>

2. scale()
  It can change the size of the element.
	scale()  : both width and height
	scaleX() : only width
	scaleY() : only height 

value- 1 to 100%

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="shortcut icon" href="../public/images/favicon.ico" type="image/x-icon">
    <style type="text/css">
        body{
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
        }

        img{
            transform: scaleX(1);
            transition:3s;
        }
        img:hover{
            transform: scaleX(2);
            transition: 3s;
        }
        .container{
            border: 15px groove;
            overflow:hidden;
        }    
    </style>
</head>

<body>
    <div class="container">
        <img src="../public/images/a4.jpg" width="300" height="200">
    </div>
</body>

</html>
