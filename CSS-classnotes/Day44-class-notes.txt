None
- It hides the element in a Page.
- It removes the allocated space for element.

syntax: 
 img{
	display:none;
 }

FAQ: What is the difference b/w "display:none" and "visiblity: hidden"?
Ans. display  : none     => "removes the allocated space".
     visiblity: hidden   => "keeps the allocated space".[Best suited when some advertisment has to come on a page]
			    " In js we will see how to remove an element, to decrease the loading time."

2. Block
	It can display elements with line break
   Inline	
	It can display elements without line break
	
You can use block|inline to displaying hidden element.

  span{
	display: block     ===> display in new line
  }

  span{
	display:inline     ===> display in same line
  }

Inline-Block
 => Several HTML elements will not allow you to change the dimensions.
 => The width and height depends on the content.
 => It can change the dimension of elements with autosize[adjust accordingly].

span{
	heigth: 200px;			=> width&height are not applied.
	width : 300px;
}

span{
	heigth: 200px;			=> width&height are applied now.
	width : 300px;
	display:inline-block;
}

Note:
Compared to display: inline, the major difference of display:inline-block is that display: inline-block allows to set a 
		     width and height on the element.
Also, with display: inline-block, the top and bottom margins/paddings are respected, but with display: inline they are not.


Compared to display: block, the major difference is that display: inline-block does not add a line-break after the element, so the element can sit next to other elements.

Flex
- It is used for container that comprises of elements.
- It is not applicable directly to elements.
- Arrange elements side by side(general idea).
- Flex have various attributes to control the orientation and allignment.

For orientation
	a. flex-row	
	b. flex-column		
	c. flex-wrap
	d. flex-nowrap
	e. flex-direction
	f. flex-row-reverse
	g. flex-col-reverse

- You can configure allignments for elements using
	a. justify-content
	b. align-items


FAQ: What is the difference b/w flex and inline?
	- Flex is used only for container that comprises of elements.
	- It can align items horizontally & vertically.

Scenario
========
<style>
	ol{
		display: flex;
	}
</style>
<ol>
   <li>HTML</li>
   <li>CSS</li>
   <li>Bootstrap</li>
</ol> 


	- Inline is used for individual elements to keep along with other elements.
	- It is not flexible for arrangements.

<style>
	li{
		display: inline;
	}
</style>
<ol>
   <li>HTML</li>
   <li>CSS</li>
   <li>Bootstrap</li>
</ol>

syntax: 
   container{
	display: flex;
   }	
  
   element{
	display: inline;
   }

- We can change the flex orientation for elements using flex-direction
	container	
	{
		display:flex;
		flex-direction: row|row-reverse|column|column-reverse
	}


- We can use the attributes like "align-items" while defining flex
- It can change the alignment of  items in container to 
	a. baseline[left when flex direction is column, top when flex direction is row]
	b. center  
	c. end[right when flex direction is column,bottom when flex direction is row]

Note: when align-items is not defined,the elements in the container will adjust their size according to width and height.


- justify-contents will provide various allignments like 
		flex-start    : [left in row, top in column]
		flex-end      : [right in row, bottom in column]
		center        : [center in row and column]
		space-around  :
		space-evenly  :
		space-between :  
	
- align-items : end,center,baseline
