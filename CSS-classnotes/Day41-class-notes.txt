Universal Selector:
- It is defined by using “*” that represents all.
- It apply effects to all elements.

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="node_modules/bootstrap/dist/css/bootstrap.css">
    <link rel="stylesheet" href="node_modules/bootstrap-icons/font/bootstrap-icons.css">
    <style type="text/css">
        *{
            font-style: italic;
        }
    </style>
</head>

<body class="container-fluid">
    <dl>
        <dt>Name</dt>
        <dd><input type="text"></dd>
        <dt>Password</dt>
        <dd><input disabled type="password"></dd>
        <dt>Mobile</dt>
        <dd><input required type="text"></dd>
    </dl>
</body>
</html>

Root selector
=============
:root 			It refers to root(highest level parent element) of document, which is ‘<html>’

Ex:
:root {
  --main-color: #3498db;
}

body {
  background-color: var(--main-color);
}


Note: 
root targets only the root element (typically <html>), whereas * targets every single element in the document.
:root is often used for global settings like CSS variables, while * is often used for universal styles like resets or base styles for all elements.



Language Selector:
- It defines effects based on lang configured for element.
- If you page is multi lingual then you can define effects to content based on specific language. “:lang()”

eg#1
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

        p:lang(kan){
            color:red;
        }
        p:lang(en){
            color:blue;
        }
        p:lang(fr){
            color:green;
        }
    </style>
</head>

CSS Colors
==========
a. Color name
b. Color shade name
c. hexadecimal[3 char | 6 char]
d. rgb()
e. rgba()
f. hsl()
g. hsla()
h. linear-gradient()
k. radial-gradient()

rgb() - red,blue,green value ranges from 0 to 255
	syntax: 
		{
			background-color: rgb(255,0,0);
		}

rgba() - red,green,blue and alpha[0 to 1]
	 syntax: 
		{
			background-color:rgba(0,0,0,0.5);
		}

hsl()  - hue,saturation,lightness
	  hue is an angle from 0 to 360 degree
	  0 to 120   => red
	  120 to 240 => green
	  240 to 360 => blue
	  saturation is grey shade with 0 to 100%
	  lightness  is brightness with 0 to 100%

css inheritance
===============
 => In css inheritance is the process of configuring parent effects to child elements.
 => child element automatically implements some of the parent feature which we can control by using follwing css values
		a. inherit
		b. initial
		c. unset

syntax: 
	{
		all: unset;	=> remove all the default styles
	}

How unset Works?
Ans.
Inherited Properties
====================
=> For properties that are normally inherited (like color, font-family, etc.), unset behaves like the inherit keyword. 
=> It will make the property inherit its value from its parent.

Non-Inherited Properties
======================== 
=> For properties that are not naturally inherited (like width, margin, border, etc.), unset behaves like the initial keyword. 
=> It will reset the property to its initial value, which is the browser's default.
