FAQ. What is the MIME type for styles?
Ans. MIME stands for Multipurpose Internet Mail Extension.
     MIME tells file and content type.
     Styles MIME type is "text/css"

Syntax: 
    <style type="text/css">
    </style>
    
Note a good practise in real-time
    a.<link rel="stylesheet" href="" type="text/css">


FAQ. What is mediatype for styles?
Ans. It configures your styles for various devices and viewport.
     We can set styles for screen,print and speech.
	syntax: 
		<style type="text/css" media="all|screen|print|speech">
		</style>

	screen: to see the effect on screen
	print : to see the effect when we take printout

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    
    <style type="text/css" media="screen">
        .container{
            padding: 20px;
            background-color: lightyellow;
            border: 3px solid black;
        }
        dl{
            display: grid;
            grid-template-columns: 6fr 6fr;
        }
        dt{
            font-weight: bold;
        }
    </style>

    <style type="text/css" media="print">
        .container{
            background-color: none;
            border: 1px solid;
            width: 300px;
            height: 200px;
            padding: 20px;
        }
        img,button{
            display: none;
        }
        dl{
            display:grid;
            grid-template-columns: 12fr;
        }
    </style>
</head>
<body>
    <div class="container">
        <img src="public/images/a1.jpg" width="200" height="100">
        <h1>Ticket</h1>
        <dl>
            <dt>Departure</dt>
            <dd> 01-09-2024</dd>
            <dt>Time</dt>
            <dd> 12.45PM</dd>
        </dl>
        <button>PrintTicket</button>
    </div>
</body>
</html>

FAQ: What is the issued with Embeded technique?
Ans. It is slower when compared with inline.
     You can't access across pages.
     Styles can be used only with in the page.


Styles in external file
=======================
=> we can write a styles in seperate stylesheet.
=> Stylesheet have extension of ".css".
=> Stylesheet can cascade over HTML pages.
    [Cascade Style Sheet]
=> You can access across pages.
=> However if you are using external files, then number of requests will increase for a page, which internally increase the 
   page load time.

Syntax: 
  1. Maintain seperate css file in folder called "styles" in "src" folder
  2. Add a new file called "ticket.css"
  3. Link to webpage using
	<link rel="stylesheet" href="src/styles/ticket.css">

eg::
ticket.css
==========
.container{
    padding: 20px;
    background-color: lightyellow;
    border: 3px solid black;
}
dl{
    display: grid;
    grid-template-columns: 6fr 6fr;
}
dt{
    font-weight: bold;
}

FAQ: What is minification?
- Minification is the process of compressing CSS.
- It is always recommended to Minify and use the CSS for production. [Live]
- CSS original file will occupy more space, we have to use them for development but not for production.

Work flow
=========
1. Copy your css code.
2. Visit the website
	https://www.toptal.com/developers/cssminifier.
3. copy the actual code and click on minify.
4. copy the minified file in css folder with a new name "****.min.css"
5. Now link the minified file to HTML file.(use minified file only in production environment)

Note: Use uncompressed file in "Development environment"[locally when we build].
      Use compressed file in "Production environment"[Go live].


FAQ: What is CDN?
     It stands for Content Delivery Network.
     It is like keeping all our dependencies in remote server and access remotely from our project.
     To use CDN internet connection is a Must.
	eg: https://icons.getbootstrap.com/
		click on icons
		scroll down to the end and see the options
			Package manager : npm install bootstrap-icons
			CDN : <link rel="stylesheet" 
				    href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
