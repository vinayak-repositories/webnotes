CSS Transition
	transition 		       : shorthand
	transition-duration            : total time taken for transition
	transition-delay               : time taken to start the transition.
	transition-property            : refers to the property that uses duration[time]
	transition-animation-function  : it applies predefined animations.

eg#3. transition-timing-function: values

The transition-timing-function property can have the following values:
ease 		      - specifies a transition effect with a slow start, then fast, then end slowly (this is default)
linear 		      - specifies a transition effect with the same speed from start to end
ease-in 	      - specifies a transition effect with a slow start
ease-out 	      - specifies a transition effect with a slow end
ease-in-out 	      - specifies a transition effect with a slow start and end
cubic-bezier(n,n,n,n) - lets you define your own values in a cubic-bezier function

To create our own animations as per the requirement, we need to go for "keyframes and animations".

					CSS keyframes and animations
					============================
keyframe - It is used to create animations for any element in page.
	 - A keyframe comprises of elements with any specified effect like size, position, orientation, color etc.
	 - A good basic animations comprises of 30 frames per second(30fps)
	
CSS can configure "tweening" animations which comprises of initial and final state.

syntax: 
  @keyframes name
  {
	from{
		initial_state;
	}
	to{
		final_state;
	}
  }

-key frame is applied to any element in page by using "animation" attributes.
	animation-name
	animation-duration
	animation-direction
	animation-iteration-count
	animation-delay
	animation-timing-function
