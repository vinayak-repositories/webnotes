Flex wrap
 - It can control wrapping of elements in container
 - If set to "nowrap", elements will adjust according to width of the container.
 - If set to "wrap", elements will span to multiple rows[depending on the width of the elements row and col will get adjusted].

syntax
 container{
	display: flex;
	flex-wrap: wrap|nowrap;
 }

CSS Grid
 => Mainly for arranging rows and columns.
 => It is used to create a responsive layout.
 => We can re-arrange the content in page dynamically according to media orientation or size.
 => We have attributes like
	a. grid.
        b. grid-row
	c. grid-column.
	d. grid-gap(deprecated).
	e. grid-template-columns.
 => A responsive grid will have max 12-columns.(which is actually 1200px)
 => we can set size of columns in fr[fraction] or in px[pixels]
 => size in "fr" is responsive.
 => grid + media queries  makes the page responsive[landscape and portrait]


Media type : screen|print|speech
orientation: portrait|landscape

syntax: 
	@media screen and (orientation : landscape|portrait){
		.....
	}

Note: To create a responsive layout, we need to configure "media queries" 
	@media type and (condition)
	{

	}
	
	type         => all|screen|print|speech
	condition    => orientation,min-width,max-width,width
	orientation  => landscape,portrait

CSS Background
==============
 background-color
 background-image
 background-size
 background-attachment
 background-repeat


Note:
background-color	: rgb
background-image	: url("")
background-repeat	: no-repeat,repeat-x,repeat-y,repeat
background-attachment	: fixed,scroll
background-position	: left,right,center | top center bottom  | x-postion y-position
background-size         : contain | cover | <length : w and h> | <percentage> | auto


background (shorthand property) : color image repeat position

syntax: 
 	background: #ffffff url("img_tree.png") no-repeat right top;


FAQ: 
1. Can we set multiple background images?
Ans. Yes, but we need to keep the alignment correctly otherwise u can't keep.

            background-size: 30% 20%,30% 50%;
            background-position: center center,top right;
        }
    </style>
</head>
<body>
    
</body>
</html>


2. Can we change background image dynamically?
Ans. Yes, using media query.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>

        body{
            height: 100vh;
        }

        @media screen and (orientation:landscape){
            body{
                background-image: url(../public/images/netflix-background.jpeg);
                background-size: cover;
            }
        }

        @media screen and (orientation:portrait){
            body{
                background-image: url(../public/images/netflix-logo.png);
                background-size: 100% 100%;
                background-repeat: no-repeat;
            }
        }

    </style>
</head>
<body>
    
</body>
</html>

3. Can we have background color and backgroud image both?
Ans. Yes
body
{
            height: 100vh;
            background-image: url("../public/images/menfashion.jpeg");
            background-repeat: no-repeat;
            background-color: black;
}

CSS text-effects
================
 Font attributes
	a. font-size
	b. font-family
	c. font-weight
	d. font-style
	e. font-variant  : small-caps [all lower case letters convert into capital letters and font size is small]

shorthand
   element{
	font: font-style font-variant font-weight font-size font-family;
   }
