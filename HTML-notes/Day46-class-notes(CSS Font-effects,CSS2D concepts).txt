While working with paragraph
  line-height    : space b/w lines
  word-space     : space b/w words
  letter-space   : space b/w chars
  word-break     : breaks lengthy words at right margin of paragraph.
			normal,break-word,break-all,keep-all

Explanation:
word-break: normal; (default behavior):
	Long words that cannot fit in the container will overflow without breaking.

word-break: break-word;:
	Breaks words at any point when they cannot fit within the container (modern browsers).

word-break: break-all;:
	Forces breaks at any character when the content overflows the container, even if it breaks the word unnaturally.

word-break: keep-all;:
	Prevents breaking words, often used for non-CJK (Chinese/Japanese/Korean) text. 
        Forces the text to overflow if there’s no natural break.

    list-style 	       : shorthand
    list-style-type    : alpa|number|roman|disc|circle
    list-style-image   : custom images
    list-style-position: inside,outside

syntax: 
   list-style : list-style-type list-style-image list-style-position;

CSS 2D effects
==============
 => 2D refers to 2-Dimension effects
 => we can change the orientation and position of element along x and y axis.
 => you can configure by using "transform" attribute.
 => Transform method for 2D are
	a. translate()
	b. skew()
	c. scale()
	d. rotate()

translate() 
- It changes the position of element along x and y axis
	translate(x,y)
	translateX()
	translateY()

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="shortcut icon" href="../public/images/favicon.ico" type="image/x-icon">
    <style type="text/css">
        img{
            transform: translateX(0px);
            transition:3s;
        }
        img:hover{
            transform: translateX(800px);
            transition: 3s;
        }    
    </style>
</head>

<body>
    <img src="../public/images/a4.jpg" width="300" height="200">
</body>

</html>

2. scale()
  It can change the size(width and height) of the element.
	scale()  : both width and height
	scaleX() : only width
	scaleY() : only height 

value > 1 : increases the height and width;
vale  < 1 : decreases the height and width;
value = 1 : no change in height and width;

eg#1.
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="shortcut icon" href="../public/images/favicon.ico" type="image/x-icon">
    <style type="text/css">
        body{
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
        }

        img{
            transform: scaleX(1);
            transition:3s;
        }

        img:hover{
            transform: scaleX(2);
            transition: 3s;
        }
        .container{
            border: 15px groove;
            overflow:hidden;
        }    
    </style>
</head>

<body>
    <div class="container">
        <img src="../public/images/a4.jpg" width="300" height="200">

3. skew()
	Tilting the element by specified angle.
	
	skew(degx,degy)
	skewX()
	skewY()

Units: 
Uses angles (deg, rad, grad, turn).
Positive values skew right.
Negative values skew left.

4. rotate()
      rotate() function in CSS is used to rotate an element around a fixed point (by default, its center). 
      The angle of rotation is specified in degrees (deg).

	rotate(angle);

rotate(45deg): Rotates the element 45 degrees clockwise.
rotate(-30deg): Rotates the element 30 degrees counterclockwise.
