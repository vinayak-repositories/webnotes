Note: 

:: selection is applied only on 

1. Text elements

<p> (paragraphs)
<h1> to <h6> (headings)
<span> (inline text)
<div> (if it contains text)
<li> (list items)

2. Form elements

<textarea> (selected text inside a text area)
<input type="text"> (selected text inside input fields)

3. Other elements with text content

<a> (links)
<blockquote> (quoted text)
<label> (form labels) 

Elements that ::selection does NOT affect:
Certain elements that do not contain selectable text will not be affected, including:
1. Images (<img>)
2. Buttons (<button>)
3. Non-selectable elements (<canvas>, <video>, etc.)

Most modern browsers support ::selection, but only limited properties can be applied, such as:
a. color
b. background-color
c. text-shadow

Properties like border, padding, margin, and box-shadow won't work.

Root selector
=============
:root 			It refers to root(highest level parent element) of document, which is ‘<html>’

Ex:
:root {
  --main-color: #3498db;
}

body {
  background-color: var(--main-color);
}


Note: 
 root targets only the root element (typically <html>), whereas * targets every single element in the document.
:root is often used for global settings like CSS variables, while * is often used for universal styles like resets or base styles for
 all elements.

CSS Colors
==========
a. Color name
b. Color shade name
c. hexadecimal[3 char | 6 char]
d. rgb()
e. rgba()
f. hsl()
g. hsla()
h. linear-gradient()
k. radial-gradient()

rgb() - red,blue,green value ranges from 0 to 255
	syntax: 
		{
			background-color: rgb(255,0,0);
		}

rgba() - red,green,blue and alpha[0 to 1]
	 syntax: 
		{
			background-color:rgba(0,0,0,0.5);
		}

hsl()  - hue,saturation,lightness
	  hue is an angle from 0 to 360 degree
	  0 to 120   => red
	  120 to 240 => green
	  240 to 360 => blue
	  saturation is grey shade with 0 to 100%
	  lightness  is brightness with 0 to 100%

css inheritance
===============
 => CSS inheritance determines how styles are passed down from parent elements to child elements in an HTML document. 
    Some properties are naturally inherited, while others are not.

Inherited Properties
====================
Some properties automatically inherit from the parent element to its child elements. These are mostly text-related properties, such as:
 1. color
 2. font
 3. letter-spacing
 4. line-height
 5. visibility
 6. cursor

Non-Inherited Properties
========================
Most box-model and layout-related properties are not inherited. These include:
1. margin
2. padding
3. border
4. width
5. height
6. background
7. position
8. display
9. flex
10. grid

Controlling Inheritance Using inherit, initial, and unset
  a. inherit : Forces an element to inherit a property from its parent, even if it's not naturally inherited.
  b. initial : Resets a property to its default value (as defined by the browser).
  c. unset   : Acts as inherit for inherited properties.
             : Acts as initial for non-inherited properties.
	
syntax: 

	{
		attribute: inherit | initial | unset;
	}

Note: If we we want all properties of parent to inherit to child then we use
	{
		all: unset;	=> remove all the default styles
	}

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Inheritance Example</title>
    <style>
        body {
            font-family: Arial, sans-serif;
            color: blue;
        }

        div {
            border: 1px solid black;
            padding: 10px;
        }

        p {
            font-size: 20px;
        }
    </style>
</head>
<body>
    <div>
        <p>Welcome to the world of CSS.</p>
        <span>Learning CSS Inheritance</span>
    </div>
</body>
</html>

Output
The text inside <p> and <span> will be blue because color is an inheritable property.  

<style>
    body {
        background-color: lightgray;
    }

    div {
        padding: 20px;
    }
</style>

Output: Here, background-color is NOT inherited. The div must explicitly set its background color; otherwise, it won't inherit from body.


Forcing Inheritance (inherit, initial, unset)
You can override default inheritance using:

a. inherit: Forces inheritance.
b. initial: Resets to the default browser value.
c. unset: Behaves as inherit for inheritable properties, initial otherwise.

div {
    color: inherit; /* Inherits from parent */
    background-color: initial; /* Resets to default */
}

            let childDisplay = window.getComputedStyle(child).display;

            console.log("Parent Border:", parentBorder);

c. scripts.js

// Select the elements
const languageSelect = document.getElementById('language-select');
const header = document.getElementById('header');
const text = document.getElementById('text');

// Function to change language
function changeLanguage(language) {
    // Set the language on the page
    document.documentElement.lang = language;

    // Change header and text content based on the selected language
    if (language === 'en') {
        header.textContent = 'Hello, welcome!';
        text.textContent = 'This is an English paragraph.';
    } else if (language === 'fr') {
        header.textContent = 'Bonjour, bienvenue!';
        text.textContent = 'Ceci est un paragraphe en français.';
    } else if (language === 'ar') {
        header.textContent = 'مرحبا، أهلا بك!';
        text.textContent = 'هذا فقرة باللغة العربية.';
    } else if (language === 'jp') {
        header.textContent = 'こんにちは、ようこそ！';
        text.textContent = 'これは日本語の段落です。';
    }
}

// Event listener for language change
languageSelect.addEventListener('change', (event) => {
  
    changeLanguage(event.target.value);
});
