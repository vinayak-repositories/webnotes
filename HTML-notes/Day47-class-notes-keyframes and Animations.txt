CSS Transition
--------------
The transition property in CSS allows smooth animations when changing CSS properties like background-color, transform, opacity, etc. 
It makes UI interactions more visually appealing.


	transition 		   : property duration timing-function delay

	property	           : The CSS property to animate (e.g., all, background-color, transform).
	duration		   : How long the transition lasts (e.g., 0.5s, 1s).
	timing-function (optional) : Defines speed variation (ease, linear, ease-in, ease-out, ease-in-out).
	delay (optional)           : Adds a delay before the transition starts (1s, 0.3s).

specific things to change
-------------------------
	transition-duration            : total time taken for transition
	transition-delay               : time taken to start the transition.
	transition-property            : refers to the property that uses duration[time]
	transition-animation-function  : it applies predefined animations.

eg#3. transition-timing-function: values

The transition-timing-function property can have the following values:
ease 		      - specifies a transition effect with a slow start, then fast, then end slowly (this is default)
linear 		      - specifies a transition effect with the same speed from start to end
ease-in 	      - specifies a transition effect with a slow start
ease-out 	      - specifies a transition effect with a slow end
ease-in-out 	      - specifies a transition effect with a slow start and end
cubic-bezier(n,n,n,n) - lets you define your own values in a cubic-bezier function

1. ease (Default)
	Starts slow, speeds up, then slows down again.
	Good for a natural feel.

2. ease-in
	Starts slow and then speeds up.
	Good for effects like loading animations.

3. ease-out
	Starts fast and then slows down at the end.
	Good for exit animations (e.g., fading out smoothly).

4. ease-in-out
	Starts slow, speeds up, and slows down at the end.
	Good for smooth, natural transitions.

To create our own animations as per the requirement, we need to go for "keyframes and animations".

					CSS keyframes and animations
					============================
keyframe - It is used to create animations for any element in page.
	 - A keyframe comprises of elements with any specified effect like size, position, orientation, color etc.
	 - A good basic animations comprises of 30 frames per second(30fps)
	
CSS can configure "tweening" animations which comprises of initial and final state.

Syntax: 
  
@keyframes animationName {
  from {
    /* Initial state */
  }
  to {
    /* Final state */
  }
}

@keyframes animationName {
  0% {
   	 /* Start */
  }
  50% {
   	 /* Midway */
  }
  100% {
    	/* End */
  }
}

-key frame is applied to any element in page by using "animation" attributes.
	animation-name
	animation-duration
	animation-direction
	animation-iteration-count
	animation-delay
	animation-timing-function

animation: name duration timing-function delay iteration-count direction fill-mode;

1. name		  : Name of the animation (same as @keyframes name).
2. duration	  : Time in s or ms for one cycle.
3. timing-function: Speed curve (ease, linear, ease-in, ease-out, ease-in-out, cubic-bezier(...)).
4. delay	  : Time before animation starts.
5. iteration-count: Number of times it repeats (infinite for endless).
6. direction	  : normal, reverse, alternate, alternate-reverse.
7. fill-mode	  : none, forwards, backwards, both.


Examples
========
animation: bounce 1s infinite;
animation: marquee 5s linear infinite;
animation: marquee-alternate 2s ease-in-out infinite alternate
animation: marquee-slide 3s linear forwards

marquee elements behaviour
==========================
   behaviour = "scroll"    : Continuous scrolling.
   behaviour = "slide"     : Moves once and stops when it reaches the end.
   behaviour = "alternate" : Moves back and forth between two edges.

Note: fill-mode attributes

both		Combines forwards and backwards

Direction attributes values
===========================
Note: 
normal			 Animation plays forwards from 0% to 100%.
reverse			 Animation plays backwards, starting from 100% to 0%.
alternate		 Animation plays forwards in the first cycle, then backwards in the next cycle (repeats).
alternate-reverse	 Animation plays backwards in the first cycle, then forwards in the next cycle (repeats).
