CSS Units
=========
 - Units define size and position.
 - They are used to define dimension and location of elements in page.
 - You can configure size with: height and width.
 - The CSS units are categorized into 2 groups
	o Absolute Length Units
	o Relative Length Units

Absolute Length Units
- They are  not relative to anything else and are generally considered as normal units.
- These are not affected by other relative elements and their units.
- They are not affected by parent or adjacent elements, they are individual and configured for various media devices.

Unit 			Name 				Equivalent to
==============================================================================
cm 			Centimetres 			1cm = 96px/2.54 =37px
mm 			Millimetres 			1mm = 1/10th of 1cm
Q 			QuarterMillimetres		1Q  = 1/40th of 1 cm 
in 			Inches 				1in = 2.54cm =96px
pc 			Picas 				1pc = 1/6th of 1in
pt			Point 				1pt = 1/72th of 1in
px 			Pixels 				1px = 1/96th of 1in

Relative length units:
- These are related to other contents in the page.
- The size of any element can be determined based on its parent, child or adjacent.
- The advantages are when parent element size is changed it will relatively affects the child element also.
- Relative units are based on another element, viewport, or font size.

Unit 				Relative To
=============================================================
em 				It uses the font size of parent element and applies to current element.[element relative]
				note: 1em   -> 100% of parent element
				      0.5em -> 50%  of parent element
				Relative to the parent element’s font size

rem 				Relative to the root element’s font size (html)

%                               Relative to parent element (for width/height)

ln 				Line height of the element.
vw 				1% of the viewport’s width.
vh 				1% of the viewport’s height.
vmin 				1% of the viewport’s smaller dimension.
vmax 				1% of the viewport’s larger dimension.

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style type="text/css">
       
       html{
         font-size: 16px;
       }

       .parent{
            font-size: 20px;
            border: 1px solid black;
            margin :25px;
            padding: 25px;
       }
       .child-em{
            font-size: 1.5em;
            color:blue;
       }
       .child-rem{
            font-size: 1.5rem;
            color:green;
       }

    </style>
    
</head>
<body>
    <div class="parent">
        <p>Root font size is 16px</p>
        <p class = "child-em">Child element with 1.5em(based on parent font size)</p>
        <p class ="child-rem">Child element with 1.5rem (based on root font size)</p>
    </div>  
</body>
</html>

Output: 
1. The <div class="parent"> has a font size of 20px.
2. The .child-em font size is calculated  as  1.5 × 20px = 30px because em is relative to the parent element's font size.
3. The .child-rem font size is calculated as  1.5 × 16px = 24px because rem is relative to the root font size defined on the <html> element.

The .child-em text (blue) will be larger because it depends on the parent size (20px).
The .child-rem text (green) will remain consistent at 24px because it relies on the root size (16px). 	


Note: 
em is relative to the immediate parent.
rem is always relative to the root <html> size.

Margin
- It specifies the space around border.
- You define by using following properties
	o margin [short hand – sets in all directions]
	o margin-top
	o margin-bottom
	o margin-left
	o margin-right

syntax: 
  {
	margin: 0px 0px 0px 0px;  <!-- TOP,RIGHT,BOTTOM,LEFT -->
  }

eg#1.

/* All sides (top, right, bottom, left) */
margin: 10px;

/* Vertical (top & bottom) | Horizontal (left & right) */
margin: 10px 20px;

/* Top | Horizontal (left & right) | Bottom */
margin: 10px 20px 30px;

/* Top | Right | Bottom | Left */
margin: 10px 20px 30px 40px;

/* Individual sides */
margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;


Padding
- It specifies the space around content
- You can define
	o Padding-left
	o Padding-right
	o Padding-top
	o Padding-bottom
	o Padding
- All options are similar like margin

syntax: 
  {
	padding: 0px 0px 0px 0px;  <!-- TOP,RIGHT,BOTTOM,LEFT -->
  }

CSS Border Image
================
 => we can set image as border by using attributes like
	border 
	border-image: source slice width outset repeat;

syntax: 
{
	border: 10px solid transparent;
	border-image : url() 1-100 stretch|space|repeat|round ;
}

border-image: source slice width outset repeat;

source: The image URL or gradient used as the border.

slice : Defines how the image is divided into regions.
width : Specifies the width of the border.
outset: Sets how much the border extends beyond the element’s box.
repeat: Determines how the image parts are displayed (options: stretch, repeat, round, space).Border Image Slicing


The border-image-slice property defines how the image is divided into 9 parts (4 corners, 4 edges, and the center).

border-image-source: url('border.png'); /* Image for the border */
border-image-slice: 30; /* Slicing the image */
border-image-width: 10px; /* Width of the border */
border-image-outset: 5px; /* Extends beyond the box */
border-image-repeat: round; /* How the image is repeated */
