Rest Parameters
===============
- JavaScript ES6 introduced Rest parameters.
- One parameter can allow multiple arguments.
- It is defined by using "...paramName".

Syntax:
	function Name(...paramName)
	{

	}

	Name(arg1,arg2,arg3,arg4,....)

- Rest parameter is an array type[] parameter.
	...paramName  ====> paramName[] ===> paramName[0] , paramName[1] , paramName[2],....

- You can access the values by using Index [property] reference of by using de-structuring.

Destructuring working with arrays
=================================
eg#1.
<script type="text/javascript">

        const cricketers = ["sachin","saurav","kohli","dhoni"];

        const[first,second,third,fourth] = cricketers;

        console.log(first)
        console.log(second)
        console.log(third)
        console.log(fourth)

</script>

Output
sachin
saurav
kohli
dhoni

eg#2.
You can skip elements using commas

const colors = ["red", "green", "blue", "yellow"];
const [firstColor, , thirdColor] = colors;

console.log(firstColor);  // "red"
console.log(thirdColor);  // "blue"

eg#3.
If there are fewer elements in the array than variables, you can assign default values

const numbers = [10];
const [a, b = 20] = numbers;

console.log(a); // 10
console.log(b); // 20


eg#4.
You can use the rest (...) operator to collect the remaining elements

const scores = [100, 90, 80, 70];
const [topScore, secondScore, ...remainingScores] = scores;

console.log(topScore);        // 100
console.log(secondScore);     // 90
console.log(remainingScores); // [80, 70]


Rules of Rest Operators
=======================
  1. Every function must have only one Rest parameter.
		function(...param1, ...param2) ===> invalid

  2. In a function we can keep normal parameter and Rest parameter also.
		function(...param1, param2) =====> invalid
		
  3. RestParameter should be the last parameter [as it reads upto end]. 
		funcation(param1, ...param2) ====> valid

Spread Operation
================
- It is the process of configuring one actual parameter with multiple values, which can spread into multiple formal parameters.

Syntax:
function Name(param1, param2, param3)
{
	
}
var values = [val1,val2,val3];

Name(...values);

FAQ: What is difference between spread and rest?
Ans : Rest is about formal parameters(function declaration)
      Spread is about actual parameters | Arguments.(function call)


Function with Return
====================
- Every JavaScript function is Void type by default.
- Void refers to : discard the return.
- Every JavaScript function
	1. allocates memory
	2. performs operation in memory
	3. destroys memory
	4. It will not return any value as there is no memory.

function Name()	
{

} // end of function => memory is erased

- A function can use "return" jump statement.

function Name()
{
	return value;
}

output = value;
