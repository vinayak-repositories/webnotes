Based on type of value an operator returns , they are further classified into following types
   a. Arithmetic operators
		+ , - , * , / , 
		%  -> modulus operator
		** -> Math.pow()
		++ -> increment
		-- -> decrement
   b. comparison operator
		==  -> equality operator
		=== -> Identical equal
		!=  -> Not equal
		!== -> Identical Not equal
		>   -> Greater than
		>=  -> Greater than equal to
		<   -> Less than
		<=  -> Less than equal to 
		
  
What is the difference b/w == and === in javascript?

== (Loose Equality)
  Checks only the values for equality.
  Performs type coercion (i.e., converts one or both values to a common type before comparing).

=== (Strict Equality)
     Checks both the value and type for equality.
     No type coercion is done.

<script type="text/javascript">
        console.log(5 == "5")
        console.log(5 ==="5")

        console.log(1==true);
        console.log(1===true);

        console.log(0==false);
        console.log(0===false);

        console.log(null==undefined);
        console.log(null===undefined);
</script>

   true false
   true false
   true false
