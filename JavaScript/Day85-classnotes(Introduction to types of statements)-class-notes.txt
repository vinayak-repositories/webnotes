looping control statements
==========================
 - Looping is the process of executing set of statements repeatedly based on given condition. 
 - Loops can be created while using
	a. for
	b. while
	c. dowhile
 - Every Loop requries
	a. initialization    => where to start
	b. condition   	     => when to stop
	c. counter	     => how to move(next/previous/stepsize)


forloop -> used by developers when they are sure about no of iterations and the iteration counter will not change 
	   dynamically.

syntax:	for(initialization ;condition ;counter)
	{
		//statements
	}
