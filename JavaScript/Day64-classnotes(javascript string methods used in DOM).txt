String formatting methods
	a. Style Binding :: element.style.propertyName = value
	b. Class Binding :: element.className = "css supplied class name";

Data  Binding refers to process the accessing the data from the source(user input to variable) and binding it to UI.
Style Binding refers to process of binding style attributes to elements dynamically.
Class Binding refers to process of binding classes to elements dynamically.

event names
===========
 a. onchange()
	<input type='text | password |email '> fires up when user modifies the value and looses the focus.
        <input type='checkbox|radio'> fires up when user checks|unchecks immediately
	<select> fires up when user selects a different option
	<input type='file'> when users selects a file
	<input type='range'> when user releases the slider handle

 b. onfocus() : when the user enters into the input field.
 c. onblur()  : when the user leaves the input field.

2. charAt(index) : it returns the character at specified index.

3. charCodeAt(index) : it returns the code of the charcter at the specified index.
				Note: A to Z [65 to 90] 
				      a to z [97 to 122]

 	syntax: var str="sachin";
		 str.charAt(1);   ====> a
		 str.charCodeAt(1) ===> 97

   syntax : var str = "sachintendulkar"

Note: 
  + operator workflow

a. When both the operands are number it perform "Addition"

console.log(5 + 10); 
console.log(3.5 + 2.5);
console.log(-1 + 4); 

b. If one operand is of string type then other operand will be converted to string and it performs "Concatination".

eg#1.
console.log("3" + 2); 
console.log(2 + "3"); 
console.log("5" + true); 
console.log("Value: " + null); 
console.log("Value: " + undefined);


eg#2.
console.log(10 + "5"); 
console.log("5" + 10); 
console.log("Result: " + 5 + 10); 
console.log(5 + 10 + " is the result");


c. If '+' is used with a single operand, it attempts to convert the operand to a number.

eg#1.
console.log(+"5"); 
console.log(+"3.14"); 
console.log(+true); 
console.log(+false); 
console.log(+null); 
console.log(+undefined); 
console.log(+"abc"); 

 - operator work flow
======================
- does subtraction when used with two numbers.
eg#1.
console.log(10 - 5); 
console.log(3.5 - 2.2); 
console.log(100 - "20"); 
console.log("50" - "30"); 

- does negation when used with a single operand.
eg#1.
console.log(-10); 
console.log(-(-5)); 
console.log(-"3.14");
console.log(-true); 
console.log(-false); 
console.log(-null); 
console.log(-undefined); 



- always converts strings to numbers (unlike +).
- gives NaN if conversion fails.
eg#1.
console.log("10" - 2); 
console.log("5" - "3"); 
console.log("10px" - 5); 
console.log("3.5" - "2.5"); 
console.log(null - 1); 
console.log(undefined - 1); 



Case study to show how to add the elements dynamically
======================================================
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dynamic List with Custom Names</title>
</head>
<body>

    <input type="text" id="nameInput" placeholder="Enter a name">
    <button id="addName">Add Name</button>
    <button id="reset">Reset</button> 

    <ul id="nameList"></ul> <!-- The list to display names -->

    <script type="text/javascript">
        let ul = document.getElementById("nameList"); // Get the existing <ul>
        let input = document.getElementById("nameInput"); // Get the input field

        document.getElementById("addName").addEventListener("click", function () {
            let name = input.value.trim(); // Get input value and remove spaces

            if (name === "") { // Check if input is empty
                alert("Please enter a name!");
                return;
            }

            let li = document.createElement("li");
            li.textContent = name;
            ul.appendChild(li); // Add to the list

            input.value = ""; // Clear input after adding
        });

        document.getElementById("reset").addEventListener("click", function () {
            ul.innerHTML = ""; // Clear the list
        });
    </script>

</body>
</html>
