Data from API
-------------
API
-> Stands for Application Programming Interface.
-> Its Purpose is to make the data available to any device and platform(operating system).
-> It has various communication mechanism
	a. SOAP
	b. ReST
        c. JSON

SOAP 
 It stands for Service Orientated Architecture Protocol
 Consumer sends XML Request and Provider Sends XML Response

ReST | ReSTful Services
 It stands for Representation State transfer.
 Consumer sends Query Request and Provider sends XML | Json Response

JSON
  It stands for Javascript Object Notation
  Consumer sends Json request and Provider sends Json Response.

Note: Creation of API -> nodes.js and express.js

Working with NASA API's to render real time data on the page
------------------------------------------------------------

 URL : https://api.nasa.gov/mars-photos/api/v1/rovers/curiosity/photos?sol=1000&api_key=DEMO_KEY

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>

    <link rel="stylesheet" href="../node_modules/bootstrap/dist/css/bootstrap.css">
    <link rel="stylesheet" href="../node_modules/bootstrap-icons/font/bootstrap-icons.css">

    <script type="text/javascript">
        function bodyLoad() {
            const URL = "https://api.nasa.gov/mars-photos/api/v1/rovers/curiosity/photos?sol=1000&api_key=DEMO_KEY"

            fetch(URL)
                .then(function(response){
                    return response.json();
                }).then(function (mars){

                    mars.photos.map(function(item){

                        var tr = document.createElement("tr")
                        
                        var tdId=document.createElement("td");
                        var tdPreview= document.createElement("td");
                        var tdCamerName = document.createElement("td");
                        var tdRoverName = document.createElement("td");

                        tdId.textContent= item.id;
                        tdPreview.innerHTML = 
					`<a href='${item.img_src}' target='_blank'><img src='${item.img_src}' width="100" height="100"></a>`;

                        tdCamerName.textContent = item.camera.full_name;
                        tdRoverName.textContent = item.rover.name;

                        tr.appendChild(tdId);
                        tr.appendChild(tdPreview);
                        tr.appendChild(tdCamerName);
                        tr.appendChild(tdRoverName);
    
                        document.querySelector("tbody").append(tr);

                    })             
            })
        }
    </script>
</head>

<body class="container-fluid" onload="bodyLoad()">
    <h3 class="mt-3">Mars Rover Photos</h3>
    <table class="table table-hover">
        <thead>
            <tr>
                <th>PhotoId</th>
                <th>Preview</th>
                <th>Camer Name</th>
                <th>Rover Name</th>
            </tr>
        </thead>
    </table>
</body>
</html>
