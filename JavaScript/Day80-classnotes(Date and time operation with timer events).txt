What is the difference b/w Object and Map? 

Object 
   -> Key are String type
   -> It is structured
   -> It is slow because it needs explicit manipulations.
   -> It doesn't have size properties to count the keys.

Map
   -> Key can be any type
   -> It is schema less
   -> It is fast because it has many implicit methods.
   -> It has size properties to count the keys.


Date type
---------
- Date type is defined by using JavaScript "Date()" constructor.
- It allocates memory for storing date type value.
- Date type is stored in "Year-Month-Day" format.
- It can handle both date and time values.

Syntax:
var departure = new Date(); 		=> loads the current system date and time

var departue  = new Date("YYYY-MM-DD Hrs:Min:Sec.MilliSeconds");
var mfd       = new Date("YYYY-MM-DD");

JavaScript date object provides various date and time methods
=============================================================
getHours() 			It returns hour number    0 to 23
getMinutes() 			It returns minutes number 0 to 59
getSeconds() 			It returns seconds number 0 to 59
getMilliSeconds() 		It returns milli seconds number 0 to 99
getDay() 			It returns weekday number 0=Sunday, 1,....6
getDate() 			It returns date number 1 to 28,29,30,31
getMonth() 			It returns month number 0=January , 1=February , .....
getFullYear() 			It returns full year [4 chars]
getYear() [obsolete] 		It returns year number as per Y2K

FAQ
---
a. What is Debouncing?
    Bouncing is technique in electornic device where function is released immediately into memory without locking.
    Debouncing is a technique where function would be locked in a memory for a specific time|duration so that we 
    can allow other task to perform in process.
 
b. How to control bouncing?
Ans. using 
	a. setTimeOut(function(){},timeOutMs); 
	b. clearTimeOut(refName);

Syntax: 
 let timeoutID = setTimeout(function, milliseconds, arg1, arg2, ...);
   function	: The function to be executed after the delay.
milliseconds	: The delay before executing the function (in milliseconds).
arg1, arg2, ... : Optional arguments that can be passed to the function.
