class members
-------------
- JavaScript classes support only following members
	a. Properties
	b. Methods
	c. Accessors
	d. Constructor

FAQ: 
1. can we define a variable has a class member?
Ans. No, But we can have variable in class as a member of any method
	class Demo{
		var x = 10; //not allowed
	}
	class Demo{
		print(){
		   var x= 10; //allowed
		}
	}

note: In JavaScript classes, variables are not directly declared inside the class like in Java. 
      Instead, properties (which hold values) are assigned inside the constructor method. 
      This is because JavaScript treats a class as a special type of function, and inside functions, 
      variables are declared using let, const, or var, which are scoped (local) and not attached to the instance.

2. Why variable can't be a class member?
Ans. It is immutable and class can have only mutable members

Property in class
=================
- It is used in class to stored the data.
- It is mutable which can change according to state and situation.

Syntax
 class Name{
	propertyName =  value;
 }

- A property can  handle type of data(not initialized undefined will be stored for both primitive and nonprimitive)
	a. primitive
	b. nonprimitive

- To access the properties of a class , we need to create an instance of class.
- "." is refered as member invoking operator.

Syntax
	class Product{
		Name;
		price;
	}

	let tv = new Product();
	tv.Name = "samsung";
	tv.price = 45000;

Accessors
---------
- They are used to configure fine grained control over properties
- Accessor can manage read and write opertion on a property
- Every property comprises of 2 accessors
	a. get()  : Getter
	b. set()  : Setter
- Getter is used to read and return the value defined in property
- Setter is used to store a new value into property


Syntax: 
	Property;

	get aliasName(){
		return this.property;
	}
	
	set aliasName(newValue){
		this.property = newValue;
	}
