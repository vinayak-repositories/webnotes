switch selector
==============
 - Switch is used to interrupt the flow of electrons in circuit[For electronic device]
 - Switches are classified into
	a. Toggle switch
	b. Push button switch
	c. Selector switch
	d. Joystick switch etc.

Selector switch is used in programming, it allows us to choose exactly the block that matches the condition

syntax:  
   switch(value|expression)
   {
	case value|expression:
		statement to be executed upon match
		break;

	case value|expression:
		statement to be exeucted upon match
		break;

	default: 
		break;
   }

FAQ:
1. Can we define switch without default ?
Ans.  Yes we can define.

2. Can we define default above or b/w cases?
Ans. Yes we can define default anywhere in the switch.

3. Can we use case without "jump statement" in switch[break]?
Ans. Yes we can define(it refers to fall through)
		eg: purchase 3 you get 3 + 1 
		    purchase 2 you get 2

4. Can we use return as a jump statement in switch?
Ans. yes we can.

5. What is the difference b/w break and return ?
Ans. break will terminate the current block but will stay in function,compiler is ON.
     return will terminate the compiling[Stop everything].
     Note: return statement can be used only in function and switch
	   break can be used only in switch or loops


6. Can we define case value as "string" or "boolean"?
Ans. yes
