constructor
===========
 - constructor is a s/w design pattern used for instantiation.
 - Instantiation is the process of creating an object for class, allocating memory and loading class members into memory.
 - At the time of creating an object using "new" , internally constructor will be called.
 - constructor normally will be used to "initialize" the instance property of the class.
 - Every class has a default constructor
 - constructor is a special type of method which executes automatically for every object.
 - javascript constructor is "ananomyous"[no-name]

Syntax: 
   class Product{

	constructor(){

	}
   }

- constructor can't be overloaded and it doesn't have any parameterized constructor.
- constructor can be parameterized and if it is parameterized then while creating an object we need to pass the parameters.
		let obj = new ClassName(parameters);

class Product {
    constructor(name) {
        this.name = name;
    }

    constructor(name, price) {  // ERROR: JavaScript does not support constructor overloading
        this.name = name;
        this.price = price;
    }
}
const obj1 = new Product("TV");  // price defaults to 0
const obj2 = new Product("Laptop", 50000);  // price is set


solution
class Product {
    constructor(name, price = 0) {  // Default value for price
        this.name = name;
        this.price = price;
    }
}

const obj1 = new Product("TV");  // price defaults to 0
const obj2 = new Product("Laptop", 50000);  // price is set

eg#4. constructor role in inheritance

class Product {
    constructor(name) {
        this.name = name;
    }
}

class Electronics extends Product {
    constructor(name, warranty) {
        super(name);  // Calls the parent class constructor
        this.warranty = warranty;
    }
}

const obj = new Electronics("TV", 2);
console.log(obj.name);  // "TV"
console.log(obj.warranty);  // 2
