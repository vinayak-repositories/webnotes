Variables
   Variables are storage locations in memory, where you can store a value and use it as a part of any expression.

Scenario1: 
 document.write("Hello "+prompt("Enter the username :: ")+"<br>");
 document.write("Hi "+prompt("Enter the username :: ")+" How r u doing today? ")

As noticed above the user has to enter the name 2 times because the user is not storing the name entered by the user.
The data would be stored on ram and on the ram the storage location we identify with "variable".

Note: variables are strongly typed in various languages they are defined with specific datatype and will not allow other types.
		int age ="john"; //invalid
		int age = 22; //valid
		int age =true; //invalid

Javascript variables are not strongly typed,they are implicitly typed[Datatype is determined according to the value assigned].
			age=22;	    //valid
			age="John"; //valid
			age = true; //valid 

Javascript variables can be used directly without declaration,if javascript is not in strict mode.
To turn on strict mode we need to tell  "use strict";


Syntax : 
 	<script>
		"use strict";
		 age = 22;				=> invalid
		document.write("Age = "+age);    
	</script>

	<script>
		 age = 22;				=> valid
		document.write("Age = "+age);    
	</script>

To declare a variable in javascript we use 3 keywords
	a. var
	b. let
	c. const

- Variables have 3 phase of configuration
a) Declaration
b) Assignment
c) Initialization


Syntax: 
   var age;     //declaring a variable
   
   age = 22;    // assigning value to a variable 
   age = 33;    // assigning value to a variable

  var age =22;  //initializing a value to variable

var(function scope, redeclared | reinitialized ) 
- It defines a function scope variable.
- You can declare in any block of a function and access from any another block in the same function.
- It allows declaring, initialization and assignment.

Note: You can redeclare | reassigned.

Var allows shadowing. It is the process of re-declaring or re-initializing same name identifier within the function scope

index.html
==========
<script src="index.js"></script>


index.js
=======
function demo() {
    var x= 10;//initializing
    if (x == 10) {
        var y = 20;//initializing
        y= 30; //assigning
        y= 40; //assigning
        var y = 50; //shadowing
    }
    document.write("x = "+x +"<br>"+" y = "+y);
}
demo();

Output: 
x = 10
y = 50
