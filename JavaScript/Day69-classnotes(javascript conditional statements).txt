Multiple Decision
==================
- We can provide multiple alternatives to perform specified task.

eg:Amazon signin [Email | mobile]

Syntax: 
	if(condition-1){
		statements for condition-1 is true
	}	
	else if (condition-2){
		statements for condition-2 is true
	}else{
		statements when all condition all evaluates to false
	}

ShortCircuit Operator
--------------------
Logical AND(&&)
- It defines multiple expression in one statement
- It returns true when all expression evaluates to true
- It returns false when one expression evalutes to false

Syntax
	expression-1 && expression-2 && expression-3

Logical OR(||)
- It defines multiple expression in one statement
- It returns true if one expression evaluates to true
- It returns false if all expression evalutes to false

Syntax
	expression-1 || expression-2 || expression-3

Programs
 a. Find the largest of 2 numbers
	eg: a>b       : a is greater
	    otherwise : b is greater

 b. Find the largest of 3 numbers
	eg: a>b && a>c : a is greater
		b>c    : b is greater
	    otherwise  : c is greater

 c. Find whether the value is in range or out of range
	eg: input to a functions : value,min,max

<script type="text/javascript">

        function findRange(value,min,max) {
            if (value>=min && value<=max) {
                document.write(`Your value ${value} is in range of min=${min} and max=${max}`)
            } else {
                document.write(`Your value ${value} is out of range min=${min} and max=${max}`)        
            }
        }
        
        findRange(prompt("Enter value"),prompt("Enter min value"), prompt("Enter max value"))
</script>
