JavaScript Input methods
------------------------
prompt()
- It is an input box provided by browser to accept input from user.

Syntax :
prompt("Message", "default_value");
prompt("Message");

- Prompt returns
Empty String [ " " ]   : Click On OK without value
String [value entered] : Click On OK with value = string
null                   : Click On Cancel with or without value

eg#1.
function createFolder() {

            result = prompt("Enter the foldername","NEWFOLDER");

            if (result==null) {
                alert("You Clicked Cancel button");
            } else if(result==""){
                alert("You didn't entered any value");
            }else{
                document.querySelector("p").outerHTML+="<h1>Folder created with name :: "+result+"</h1>";
            }
}

<button onclick="createFolder()">Create a Folder</button>
<p></p>

2. Query String

- It is a reference value created and appended into browser as URL.
- It is present in browser address bar.
- User can input a value into page from query string.
- Query string is appended into URL using "?"

	page.html ? uname=john
	page.html ? uname=john&age=23

- Querystring is accessed and used in page by using Browser Object [BOM] "location".
- On String object we have used methods like
	indexOf("") -> returns the index of a specified character.
	slice(start)-> returns the String from the starting position to the ending of the String.

eg#1.
function bodyLoad() {
        string = location.search;                
	document.querySelector("span").innerHTML=string.slice(string.indexOf("=")+1)
}
<body onload="bodyLoad()">
    Your Name : <span></span>
</body>

input : http://127.0.0.1:5501/javascript-examples/index.html?name=sachin
output: Your Name : sachin 

3. Form Input Elements
- You can accept input from user by using various form elements like
	textbox
	password
	checkbox
	dropdown
	listbox
	number, range, radio, etc..

- All form elements have an accessor called "value" which is used to get and set the value.
- we can read value defined in input element using "value" property.
