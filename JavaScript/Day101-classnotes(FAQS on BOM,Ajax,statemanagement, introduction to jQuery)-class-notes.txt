8. How to prevent default event?
ans. Generic elements have default events, that would fireup automatically, we can prevent the default elements using
	event method called "preventDefault".
	
       function submitClick(e){
		e.preventDefault();
       }
      <form onsubmit="submitClick(event)">
	<button>submit</button>
      </form>

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <form action="" method="get" onsubmit="blockSubmit(event)">

        Username <input type="text" name="userName" id="">
        <button>submit</button>

    </form>
    <script type="text/javascript">
        function blockSubmit(e) {
            e.preventDefault();
            alert('form will be submitted to server');
            console.dir(e);    
        }

        console.dir(document.querySelector("button"));
    </script>
</body>
</html>

9. How to stop propogation/event propogation?
Ans. If we click on parent element only parent element event will fireup.
     If we click on child element ,then child element event will fireup also on parent element parent event would fireup.
     To stop this propogation : e.stopPropagation()

Problem
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script type="text/javascript">
        function containerClick() {
            alert(`clicked on container`);
        }
        function submitClick(){
            alert(`clicked on submit btn`);
        }
    </script>
</head>
<body>
    <div class="container" style="width:200px; border: 2px solid black; padding: 20px;" onclick="containerClick()" >
        Container <button onclick="submitClick()">submit</button>
    </div>
</body>
</html>
Output
   If we click inside div container : clicked on container will fireup
   If we click on button 	    : clicked on submit btn & clicked on container will fireup.

Solution
 <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script type="text/javascript">
        function containerClick() {
            alert(`clicked on container`);
        }
        function submitClick(e){
            alert(`clicked on submit btn`);
	    e.stopPropagation()
        }
    </script>
</head>
<body>
    <div class="container" style="width:200px; border: 2px solid black; padding: 20px;" onclick="containerClick()" >
        Container <button onclick="submitClick(event)">submit</button>
    </div>
</body>
</html>

Output
   If we click inside div container : clicked on container will fireup.
   If we click on button 	    : clicked on submit btn.

10. How to submit form using the events of other elements in a page?
Ans. By calling form element submit() on any browser event.

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script type="text/javascript">
        function submitForm() {
            document.querySelector("form").submit();
        }
    </script>
</head>
<body>
    <form action="../javascript-ajax/load-product.html" >
        Select City : 
        <select name="city" id="" onchange="submitForm()">

            <option value="HYD">Hyderabad</option>
            <option value="BGLR">Bengaluru</option>
        </select>
    </form>
</body>
</html>
