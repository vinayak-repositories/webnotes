Code Reusability and Extensibility
==================================
  Code Reusability   : It is the process of accessing code from one module and use it another module.
  Code Extensibility : It is the process of extending the module without disturbing the existing features.

You can achieve Code Reusability and Extensibility using two techniques
	a. Aggregation [HAS-A]
	b. Inheritance [IS-A]

Aggregation 
 => It is the process of accessing the members of one class in another class without configuring any relation b/w the classes.
 => It uses Object to Object communication, it is often termed as "HAS-A" relation.
 => We can access members of existing class in another class by using the instance of the class which is know as "Aggregation".


Syntax: 
 	class A{ 
		print(){}
	}

	class B{
		print(){
			 let obj =new A(); //Aggregation : HAS-A relationship
			  obj.print();
		}
	}

Note: Extensiblity is required to achieve
	a. BackwardCompatibility
	b. Multi Versioning Environment

Inheritance
   => Configuring the relationship b/w classes to access members of one class in another class.
   => Mechanism is termed as "IS-A" relationship.
   => Newly created class extends existing class.
   => Existing class (super|parent) , Newly created class (sub|child).
   => To access the members of parent class in child class we use "super" keyword.
   => Instance of parent class is not needed to access the members of parent class.


Syntax: 
  class A{
	print(){

	}
  }

  class B extends A{
	print(){
		super.print(); // Base class print() is accessed here	
	}
  }

Inheritance
 A dervied-class constructor must call base-class constructor called.
 In many OOP language calling parent class constructor from child class is implicit, but in javascript it is explicit.
 Baseclass constructor will be called first followed by childclass constructor.

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>

    <script type="text/javascript">

        class BaseClass{

            constructor(){
                document.write(`BaseClass constructor is called <br>`);
            }

        }

        class DerivedClass extends BaseClass{
            constructor(){
                super();
                document.write(`DerivedClass constructor is caleld`);
            }
        }

        let obj = new DerivedClass();
    

    </script>


</head>
<body>
    
</body>
</html>

Output
BaseClass constructor is called
DerivedClass constructor is called
