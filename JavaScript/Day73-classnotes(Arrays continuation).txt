Note: ES5 and higher version introduced Array destructuring technique

Without Destructuring technique
===============================
 var arr = ["Samsungtv - 45000.00","Fastrackwatch - 3500.0"]
   
 var tv    = arr[0]
 var watch = arr[1]
 
Syntax using Destructuring technique
====================================
 var products = ["Samsungtv - 45000.00","Fastrackwatch - 3500.0"]
 var[tv,watch] = products

 var[tv,watch,mobiles] products

Note :for mobiles :: undefined will be stored

=> Javascript provides various methods and properties to manipulate an Array
=> Manipulation includes querying, adding, removing and sorting etc.

1. Reading values from array | Reading array elements
	toString()  : It returns array elements seperated with ","
	join()	    : It returns array elements with custom delimitor
	map()	    : It returns array elements using iterator[Best approach used in realtime coding]
	forEach()   : It returns array elements and their index references.
	find() 	    : It returns the first occurance of the elements that matches condition
	filter()    : It returns the elements that match specified condition
	slice()     : It returns elements b/w specified index
	
Note: we can use explicit techniques for reading and returing values from an array

	for..of     : it is a statement that returns all elements
	for..in     : it is a statement that returns all properties
	for 	    : it is a loop that return elements using counter condition and iterator.

FAQ: How to present array elements into HTML document by binding with HTML elements?
Ans. By creating HTML elements dynamically using iterators and appending into documents.

FAQ: How to create HTML document dynamically?
Ans. using a method called document.createElement("p|div|img|a|li")

FAQ: How to add elements into a page?
Ans. using a method called
	appendChild()
	append()
