Boolean type
------------
 It is used for decision making in computer programming
 value for Boolean type are "true false"
 Boolean type can also be verified by using
		true  = 1
		false = 0

Syntax: 
	var isMarried = true
	var isAlive   = false

	if(isMarried == 1) {}   ====> not recomended
	if(isAlive   == false)  ====> recomended

HTML boolean attributes
	a. readonly		<input type='text' readonly> : by default it is true.
	b. checked
	c. required
	d. disabled
	e. border		<img border="0"> <table border="0|1">

FAQ:
1. What is the result if true + true
ans. 2

2. What is the result of true + "A"
ans. trueA

3. What is the result of true + 11
ans. 12

4. How to convert String "true" to boolean true?
ans. var input ="true"
     var output = (input=="true") ? true : false
     console.log(typeof output) //boolean

Decision making operators and statements
	
	== 		Equal
	===		Identical Equal
	!=		Not Equal
	!==		Identical Not Equal
	>		Greater than
	<		Lesser than
	>=		Greater than or equal
	<=		Less than or equal
	&&		Logical and
	||		Logical or
	!		Not

FAQ: What is the difference b/w == and === ? 
Ans.  "==" compares value of different types
      "===" compares values of same types



FAQ: How to compare a value with regular expression?
Ans.   By using a string method called "match()"
		var mobile = "+91987654210";
		var regExp = /\+91\d{10}/;

		mobile ==  regExp     ===> invalid
		mobile === regExp     ===> invalid
		mobile.match(regEx)   ===> valid
