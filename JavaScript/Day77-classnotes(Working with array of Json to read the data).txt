
1. How to read all keys from Object?
Ans. By using object.keys() and by using for... in iterator

eg#1.
<script type="text/javascript">
    fetch("../data/product.json")
    .then(function (response){
        return response.json();
    }).then(function (product){
        Object.keys(product).map(function(key){
            document.write(key +"<br>")
        })  
    })
</script>
	
Output
Title
Price
Features
Ratings
Photo

eg#2.
<script type="text/javascript">
    fetch("../data/product.json")
    .then(function (response){
        return response.json();
    }).then(function (product){
        for (const key in product) {
            document.write(key +"<br>")
        }
    })
</script>

Output: 
Title
Price
Features
Ratings
Photo

2. How to know the datatype of value in a Key?
eg#1.
<script type="text/javascript">
    fetch("../data/product.json")
    .then(function (response){
        return response.json();
    }).then(function (product){
        Object.keys(product)
            .map(function(key){
                document.write(`${key}================= ${typeof product[key]} <br> `);
        })
    })
</script>

Output
Title================= string
Price================= string
Features================= object
Ratings================= object
Photo================= string

5. How to remove a key dynamically?
Ans. using javascript delete operator
	syntax: delete objectName.key

<script type="text/javascript">
        fetch("../data/product.json")
        .then(function (response){
            //convert binary to Json format
            return response.json();
        }).then(function (product){
            //reading the json data 
            delete product.Ratings

            Object.keys(product).map(function(key) {
                document.write(`${key} ===> ${product[key]} <br>`);
           })
        })
    </script>

Output
Title ===>    Apple iPhone 15 (Blue, 128 GB)

6. How to check the availablity of an key in Object?
Ans. By using javascript "in" operator.

	syntax: Key in Object ====> true if exists otherwise returns false

eg#1.
    <script type="text/javascript">
        fetch("../data/product.json")
        .then(function (response){
            //convert binary to Json format
            return response.json();
        }).then(function (product){
            //reading the json data 
            if ("Stock" in product) {
                document.write("Stock Details are :: "+product.Stock)
            }else{
                document.write("Product Stock details not available");
            }
        })
    </script>

Output
  Product Stock details not available

Object with functions
 a. An object can keep all related data and functions together
 b. Functionality defines the actions of objects.
 c. In javascript functionality is defined using "functions"
 d. A function can be a void function or a function with return type
   
Syntax: 
    var object = {
			Key : value;
			key : function(){}		==> function with void
			key : function(){
					return value;   ==> function with return type
				}
		 };


Demonstrating the logic with data

eg#1
<script type="text/javascript">

    var product = {
        "Name" : "NikeCasuals",
        "Qty" : 2,
        "Price" : 3500.53,

        "Total" : function(){
            return this.Price * this.Qty;

</script>
