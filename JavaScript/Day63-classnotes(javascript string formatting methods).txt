JavaScript String
=================
- String is a literal with group of characters enclosed in

	a) Double Quotes " "

	b) Single Quotes ' '

	c) Backticks ` `

- A literal means alphanumeric and special characters

eg#1.
   str1 = "sachin";
   str2 = new String("sachin");

   console.log(typeof str1);  // string
   console.log(typeof str2);  // object


eg#2. 
   str1 = "sachin";
   str2 = new String("sachin");

   console.log(str1 == str2);   //true
   console.log(str1 === str2);  //false

eg#3.
   str1 = "sachin";
   console.log(str1.length); //6

eg#4. 
     str1 = "sachin";
     str1.age = 25;

     str2 = new String("sachin");
     str2.newProp = "hi";

     console.log(str1.length); //6
     console.log(str2.length); //6

     console.log(str1); //sachin
     console.log(str2); //String{'sachin', newProp:'hi'}

Note: 
Double and Single quotes are used for inner and outer strings.

	var link = "<a href='home.html'> Home </a>";
	var link = '<a href="home.html"> Home </a>';

String with single and double quote requires lot of contact technique with dynamic value.
	[ string + dynamic + string ]

Syntax:
"string" + var + "string" + (expression) + "string";


- ES5+ versions can use "backtick" for string.
- Backtick allows a string which can embed expression
- ES5+ versions introduced data binding expression  `${ }`

JavaScript provides various methods to format and manipulate the String.
JavaScript treats String as an Object.[It is actually an array of characters].
		welcome => ['w','e','l','c','o','m','e']

JavaScript provides various methods for String formatting and mainpulations
	bold()
	italics()
	fontcolor()
	fontsize()
	sup()
	sub()
	toUpperCase()
	toLowerCase() etc..

Note: These string formatting functions must be used on "NonRC" type elements.

Javascript provides limited set of methods for String formatting, if we want to apply css formatting to String then we must apply using
"style" property.
In css style property are defined with specific format, but in javascript style property is defined using "camelCase".

			CSS				   Javascript
		background-color 			backgroundColor
		text-align 				textAlign
		margin-left 				marginLeft

Syntax
======
	var str = "Welcome";
	str.style.fontWeight=20px;
	str.style.textShadow="2px 2px 2px gray";

The process of configuring styles to HTML elements dynamically using Javascript is called as "Style Binding".
Note: Style Binding is applicable only for elements not for String.
