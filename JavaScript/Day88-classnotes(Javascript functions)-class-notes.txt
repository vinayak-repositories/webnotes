}

- JavaScript function can be configured by using 2 techniques
	a) function declaration : memory allocated for function will be same across multiple request.
	b) function expression  : memory allocated will change as per the situtation and state.

2. function Declaration

Declaration Syntax:
function Name(params){

}


Note: 
function Print(msg)
{

}
function Print(msg) 	=> declaration
Print(msg) 		=> signature
{ } 			=> definition

A function signature is used to access the function from any location.

Ex:

	function PrintNumbers(){
		for(var i=1; i<=10; i++){
			document.write(i + "<br>");
		}
	}
	PrintNumbers();

Function parameters
-------------------
Function Parameters:
- In a function, Parameter is required to modify the function.
- A function can change its functionality according to state and situation.
- Parameter is used for changing the functionality


Syntax:
function Print(msg) => msg is formal parameter, It is just a memory allocated to store value
{ 

}
Print("welcome"); => actual parameter


eg#1.
<script>
	function PrintNumbers(howMany)
	{
		for(var i=1; i<=howMany; i++){
			document.write(i + "<br>");
		}
	}
	PrintNumbers(9);
	PrintNumbers(5);
</script>


- Every function have parameters configure as
	a) Formal Parameter
	b) Actual Parameter

- Formal Parameter is a reference and Actual Parameter is a value.
- The parameters defined in function declaration are known as "Formal Parameters".
- The parameters defined in function calling are known as     "Actual Parameters".
		Formal_Parameter = Actual_Parameter;

- Actual parameter can be any type
	a) Primitive
	b) Non Primitive Type
	c) Function type

eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

        demo([10,20,30])
        demo(function(){});

Your value is sachin and its type       :: string

Your value is 10,20,30 and its type     :: object
Your value is function(){} and its type :: function

- Parameter in a function is always "required" meaning it is mandatory.
- If value is not assigned then it returns "undefined".
