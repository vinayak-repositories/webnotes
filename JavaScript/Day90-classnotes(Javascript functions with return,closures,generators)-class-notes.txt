Function with Return
   A function with Return allows to configure the functionality and store the data.
   A function can return any type of data
		a. Primitive
		b. Nonprimitive
		c. Function


eg#1. Function returning primitive type (Number)

<script type="text/javascript">

       function addTwoNumber(a,b){
            return a+b;
       }

       function printResult(){
            document.write(`Result is : ${addTwoNumber(10,30)}`);
       }

       printResult();

</script>

Output
Result is : 40


eg#2. Function that return an Array

<script type="text/javascript">

       function getCategories(){
          return ["ALL","MEN","WOMEN","ELECTRONICS"];
       }

       getCategories().map(function(category){
          document.write(category + "<br>");
       })
       

</script>

Function Closures
-----------------
 => It is a technique used in function configuration where the members of outer function are accesible to inner function.
 => Every function by default uses closure mechanism.

Syntax: 
   function Outer(){
	
	var a = 10;
	function Inner(){
		//a  is accessible in inner
		var c = 30;
		return c;
	}
	//To make c accessible in Outer we need to return c from inner otherwise it is not possible
  }

Function Recursion
------------------
Recursion is a technique where function is called within the context of same function.
It is mainly used to configure batch files.

Syntax
------
function name(){
   name();   ---> Calling the function within the same function
}

Function Generator
=================
  Note: yeild  : return and continue to next statement
	return : return the value and stop the execution


eg#1.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script type="text/javascript">
        
        var arr=["sachin","saurav","dhoni","kohli"];

        for (const value of arr) {
            console.log(value);
        }


	// Usage of generators
        function* generatorFunction(){
            yield "sachin";
            yield "saurav";
            yield "dhoni";
            yield "kohli";
        }

       const iterator =  generatorFunction();
       console.log(iterator); //{next() : function}

       let result = iterator.next();
       console.log(result);  //{value : "sachin" , done: false} : indicating still more values can be yielded.

       while(!result.done){
            console.log(result.value);
            result=iterator.next();
       }
    </script>
</head>
<body>
    
</body>
</html>
