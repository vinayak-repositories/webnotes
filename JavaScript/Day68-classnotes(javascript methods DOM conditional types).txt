Conditional Statements
----------------------
 - A statement is used to control the execution flow in a program.
 - Conditional statements are used in decision making
 - They are also known as Selection statements.
 - JavaScript selection statements are defined using
		a. if
		b. else
		c. switch
		d. case 
		e. default
 

if statement
------------
 a. forward jump
 b. simple decision
 c. multilevel decision
 d. multiple decision


forward jump
  - It is a decision making approach where there is no alternative.
  - User will go to next only when the current condition is satisfied.
  
syntax
	if(condition)
	{
		//statement of true part
	}

2. Simple Decision
 - It provides an alternative to execute when the condition given is false
 - Alternative is defined using "else"

syntax: 
 	if(condition){
		//true
	}else{
		//false
	}

3. Multilevel decession
	- In this approach it uses forward jump and checks every condition individually.
	- It can identify the exact issue and report in multiple conditions.

syntax: 
	if(condition-1)
	{
		if(condition-2)
		{
			stmt on condition-1,condition-2 true
		}
		else
		{
			stmt on condition-2 false
		}
	}else{
		stmt on condition-1 is false
	}
