Carousel Component
==================
- It is used to create sliding and fading banners.
- We can create a slide show of content, which can be controlled manually and with automation.

Basic Carousel Classes
======================
 .carousel
 .carousel-inner
 .carousel-item
 .carousel-fade
 .carousel-slide

Syntax: 
	<div class="carousel">	
		<div class="carousel-inner">
			<div class="carousel-item">
				... your content here ...
			</div>
			... add multiple items ...
		</div>
	</div>

- Carousel item cannot display any item directly.

- Carousel needs any one item set to active.[only one item must be active]
	<div class='carousel-item active'>
	</div>

- Carousel can't start the animation directly, we need to define the attribute "data-bs-ride" for Carousel.
	<div class="carousel" data-bs-ride="carousel">

- Carousel doesn't have any default transition, we have to set the transition using classes
	a. slide
	b. carousel-fade
	
	<div class="carousel slide" data-bs-ride="carousel">
	<div class="carousel carousel-fade" data-bs-ride="carousel">

Carousel Controls
=================
- You can add controls for Carousel so that user can navigate to previous and next slide

Classes.
 .carousel-control-prev
 .carousel-control-prev-icon
 .carousel-control-next
 .carousel-control-next-icon
 .carousel-dark(deprecated in 5.3.0V)

- Carousel controls are normally buttons.

Syntax: 
 <button class="carousel-control-prev">
        <span class="carousel-control-prev-icon"></span>
 </button>

 <button class="carousel-control-next">
        <span class="carousel-control-next-icon"></span>
 </button>

- Carousel controls needs jQuery attributes to handle navigation
	
	data-bs-slide="prev"
	data-bs-slide="next"
	data-bs-target="#carousel_id"

Carousel-indicators
===================
- Indicators allow to navigate randomly
- We can navigate to any slide directly by using indicators.

Class
 .carousel-indicators

- Usually indicators is a collection of buttons.
- indicators require jQuery attribute "data-bs-slide-to=indexNumber".
- index no of items will start with  "0".

	<button data-bs-slide="0" data-bs-target="#carouselId"></button>

- Any one indicator must be active.
	<div class="carousel-indicators">
    		<button type="button" data-bs-target="#carouselExampleDark" data-bs-slide-to="0" class="active"></button>
        </div>

						Modals
						======
- It is used to create a pop-up dialog box in a page.
- In javascript we see alerts, but these alerts are embeded to the page.

Classes
 .modal
 .modal-dialog
 .modal-content
 .modal-header
 .modal-body
 .modal-footer

Attributes are 
 .data-bs-toggle
 .data-bs-target
 .data-bs-dismiss

Syntax: 
 <div class="modal">
  <div class="modal-dialog">
    <div class="modal-content">

      <div class="modal-header">
       		-- header goes here --
      </div>

      <div class="modal-body">
        	-- body goes here -- 
      </div>

      <div class="modal-footer">
		-- footer goes here --       
      </div>

    </div>
  </div>
</div>
