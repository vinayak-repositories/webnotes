Bootstrap continuation
======================
Collapse : It is used to show/hide content dynamically.

Classes
 .collapse
 .show

attributes
 .data-bs-target(specify the id of the element we target)
 .data-bs-toggle(specify the component)

Accordion
=========
It configures set of components with collapse feature,however they exhibit mutex mechanism.
It enables  only one option to display out of all options available.
If you expand one category, otherse will collapse.

	
Classes
   .accordion
   .accordion-header
   .accordion-body
   .accordion-collapse
   .accordion-item
   .accordion-button
   .show
   .collapse

Attributes
  .data-bs-target
  .data-bs-toggle
  .data-bs-parent

Dropdown
 - It allows the user to select one option from group of choices.
 - HTML drop down is designed with <select> element and it is RC datatype.
 - It is good for dynamic list
 - If we want static list with navigation and with complex data like images,icons etc then you can use bootstrap dropdown.

Note: HTML dropdown supports only RC Data type elements(only plain text).
 
Classes
  .dropdown
  .dropup
  .dropend
  .dropstart
  .dropdown-toggle
  .dropdown-item 
  .dropdown-divider

Attribute
  data-bs-toggle


Syntax: 
  <div class="dropdown">
	<button class="dropdown-toggle" data-bs-toggle="dropdown">Content goes here</button>
	<ul class="dropdown-menu">
		<li>
			<a class="dropdown-item">
				<span class="dropdown-item-text">data-goes-here<span>
			</a>
		</li>
	</ul>
  </div>

Nav with Tabs
-------------

- It is used to create tab based navigation in page.
- You can create multiple tab content so that user can switch b/w categories in one page

Classes
 .nav
 .nav-item
 .nav-link
 .nav-tabs
 .nav-pills
 .tab-content
 .tab-pane
 .active

jquery classes used are
  data-bs-toggle="tab"
  data-bs-target="#id of div" | href="#id of div"
 
Syntax: 
    <ul class="nav">
        <li class="nav-item">
		<a class="nav-link" href="#tab1" data-bs-toggle="tab">
				--content goes here--
		</a>
        </li>
    </ul>

    <div class="tab-content">  
        <div class="tab-pane" id="tab1">
		---content goes here----
        </div>
    </div>
