Progress Bar
============
It can show status of the tasks performed by actions in page
Actions including downloading,uploading,copying,installing, etc

classes
 .progress
 .progress-bar
 .progress-bar-animated
 .progress-bar-striped

The progress is defined in progress bar with style attribute width.

  <div class="progress">	
    <div class="progress-bar" style="width:50%">
    		50% COMPLETED
    </div>
  </div>

A progress can display multiple progress bars
	<div class="progress">
		<div class="progress-bar" style="width:50%">
    			50% COMPLETED
    		</div>
		<div class="progress-bar" style="width:40%">
    			40% Processing
    		</div>
        </div>

Bread Crumb
-----------
 It is used to display the phases of any actions performed on the page
 It shows the current active state and previous state in the process

classes
  .breadcrumb
  .breadcrumb-item


syntax
 <ol class="breadcrumb">
    <li class="breadcrumb-item">
		<a href="#">Home</a></li>
    <li class="breadcrumb-item active">
	Library
    </li>
 </ol>

Working with tables
===================

.table
.caption-top
.table-hover
.table-striped
.table-striped-columns
.table-active (apply on row)
.table-bordered, .border-{contextual}
.table-borderless
 
.table-dark | .table-light
.table-group-divider (apply on tbody)
.table-{contextual}(apply on table,tr,td)
