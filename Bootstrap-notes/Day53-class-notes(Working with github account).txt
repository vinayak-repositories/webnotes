Deploying on Git
---------------
 a. Create a new git account
	  https://github.com/

 b. Login to github account

 c. Click on "Create a new repository" [new button]
	Repository name *  : ui-portfolio
	Description 	   : anything about this project
	Access type 	   : public
        Add a readme file  : select the check box
	Create a repository: click on the button

d. Download and install git desktop
	https://desktop.github.com/download/

e. Open git desktop and login to github

f. Go to file menu => clone repository
     Select your repository name and set physical path
	repository-name : ui-portfolio
	physical path   : D:\folder where you are keeping the projects

g. Click on clone button

h. Open visual code => Open your project folder
	D:\folder where you are keeping the projects

i. Add package.json
	npm init -y

j. Add index.html file in project folder

k. Add folders
	a. public  	=> images,docs,videos
	b. src 		=> styles and scripts

	Note: You have to use CDN links for libraries

l. In index.html page link all bootstrap related CDN
	<link rel="stylesheet" 
		href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/
		bootstrap-icons.min.css">

        <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" 
         rel="stylesheet" integrity="sha384-QWTKZyjpPEjISv5WaRU9OFeRpok6YctnYmDr5pNlyT2bRjXh0JMhjY6hW+ALEwIH" 
	 crossorigin="anonymous">

	<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" 	
		integrity="sha384-YvpcrYf0tY3lHB60NNkmXc5s9fDVZLESaAA55NDzOxhy9GkcIdslK1eN7N6jIeHz" 	
		crossorigin="anonymous">
	</script>

m. Design the webpage(index.html) using bootstrap classes and jquery

n. Goto github repository page in browser
	select settings in repository page
		a. select pages.
		b. select the branch as main,select folder as root
		c. select save option.

o. Go to git desktop
	Now the changes made through vscode(index.html,package.json and folder created) is recognized by git desktop

p. Give some comment and click on commit to main button.

q. click on push origin(this would send the code from vs code to github)

r. Now go to the code in the github repository
	select settings in repository page
		a. select pages.
		b. Your site will be live : https://youraccount.github.io/ui-portfolio


Note: Everytime to update the repository
	a. Open the project in vs code and make the suitable changes as per the requirement
	b. Open git desktop => Do commit => Push Origin
