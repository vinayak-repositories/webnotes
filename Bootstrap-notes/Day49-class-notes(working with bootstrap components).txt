Bootstrap
  It is a component library, through which UI can be build effectively.
  Component contain : markup(HTML),style(CSS) and logics(JavaScript library : jquery)

Bootstrap-5V library
====================
1. Install bootstrap library in your project
	>npm install bootstrap --save
	>npm install bootstrap-icons --save
	>npm install jquery --save 

2. Link the following files to your webpage where you want to use complete bootstrap
	<head>
		<link rel="stylesheet" href="../node_modules/bootstrap-icons/font/bootstrap-icons.css">
    		<link rel="stylesheet" href="../node_modules/bootstrap/dist/css/bootstrap.css">		
	</head>
	<body>
		<!-- For Better peformance keep scripts in body section -- > 
		<script src="../node_modules/jquery/dist/jquery.js"></script>
    		<script src="../node_modules/bootstrap/dist/js/bootstrap.bundle.js"></script>
	</body>

Note: For scripts order is compulsory, first keep jquery.js and later keep bootstrap.bundle.js
      we can use complete bootstrap library except "poper" we will learn poper at the end.

jQuery attributes
	Bootstrap components use jQuery attributes to configure and handle functionality.
	Bootstrap5 version defines the attributes using "data-bs-{}"
	Bootstrap Upto4 version defines the attributes using "data-{}".

	Bootstrap jquery attributes are of various types
		a. data-bs-target
		b. data-bs-toggle
		c. data-bs-dismiss
		d. data-bs-slide
		e. data-bs-ride etc..

To close any component in bootstrap you can attach the attribute called "data-bs-dismiss" to any clickable element like[button,links]
		<button class='btn btn-close' data-bs-dismiss='component-name'>

		eg:: <button class='btn btn-close' data-bs-dismiss='alert'>
